# Barracuda CGF API Dashboard for Grafana

This folder contains a Grafana dashboard for Barracuda CloudGen Firewall (CGF) metrics collected through the Zabbix API-based template.

## Dashboard file

- `Grafana - Barracuda CGF - API.json`

## What it shows

The dashboard is designed to visualize data already collected by Zabbix from the Barracuda CGF REST API. It reads from the Zabbix datasource and filters by host group and host. It is intended for environments where the host is monitored with the API template, not with an agent installed on the firewall.

Main sections included in the dashboard:

- Box status overview
- System information
- Site-to-site VPN status and throughput
- S2S VPN in/out and session volume over 24h
- CPU breakdown and load overview
- Memory usage
- Management sessions and users
- Firewall traffic and QoS analysis
- Interface traffic, packets, inventory, and errors
- Filesystem usage and root disk free space
- License and security subscription expiry/state
- Uptime and session counters

## Requirements

Before importing the dashboard, make sure the following are in place:

1. The Zabbix datasource is available in Grafana.
2. The Barracuda CGF API template is imported into Zabbix.
3. The firewall host is linked to the template.
4. API access is configured with valid authentication and URL macros.
5. The host selection variables are populated from the Zabbix datasource.

The dashboard uses the following Grafana variables:

- `Group` — Zabbix host group
- `Hostname` — one or more Barracuda hosts in the selected group

## Data source and template relationship

This dashboard expects item names and keys generated by the API template for Barracuda CGF, especially items such as:

- `cgf_box_*`
- `cgf_service_*`
- `cgf_vpn.s2s.*`
- `cgf_if.*`
- `cgf_fw.*`
- `cgf_license.*`
- `cgf_subscription.*`

The queries in the dashboard use direct SQL against the Zabbix database and select the latest values from the relevant history tables.

## Import procedure

1. Open Grafana.
2. Go to Dashboards → New → Import.
3. Upload `Grafana - Barracuda CGF - API.json`.
4. Select the Zabbix datasource used by your environment.
5. Confirm that the `Group` and `Hostname` variables resolve correctly.
6. Save the dashboard.

## Usage

After import, select the required host group and one or more Barracuda hosts. The dashboard is meant for quick operational review and should be used as a live overview rather than a replacement for deeper Zabbix alert investigation.

Recommended usage:

- Start with the `Box Status` and `System Info` panels to confirm the firewall is reachable and healthy.
- Check `CPU`, `Memory`, and `Root disk free` before investigating performance or capacity issues.
- Use the VPN and firewall panels to validate traffic and tunnel health during incidents.
- Review `Licenses & subscriptions` when certificate or subscription expiry is expected.
- Check `Interface inventory` and `Interface errors` when a link or adapter is suspected.

If some panels return empty values, verify that:

- the Zabbix host belongs to the selected group,
- the Barracuda API template items are present and enabled,
- the Zabbix datasource connection is valid,
- the host names match the values returned by the Zabbix host variable.

## Notes

- The dashboard is specifically built for the API monitoring flow and not for SNMP-based Barracuda monitoring.
- The view is optimized for operational visibility and quick health checks, not for deep forensic analysis.
- If the item naming or API responses differ on your Barracuda firmware version, some panels may require minor adjustments.
